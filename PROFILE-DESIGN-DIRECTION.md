## Visual vocabulary

- Editorial, quiet Nordic composition; confident hierarchy and real whitespace.
- Shared neutrals: Paper `#F6F5EF`, Ink `#25312E`, Soft Gray `#D7DCD6`.
- KIERTO accent: Moss `#597962`, Sage `#BACABD`, Clay `#C88A70`.
- TRACE accent: Teal `#38A8A1`, Deep Slate `#172C32`, Mist `#DCEAE7`.
- No animated GIF statistics, skill rating bars, random badges, fake metrics, or generic "passionate about" language.
- Use semantic alt text, maintain contrast, and keep the content readable if GitHub disables images.

## Profile architecture

1. A wide, SVG-rendered identity banner, designed specifically for Sabnam.
2. A short professional role and current degree line above the fold.
3. A first-person summary that explains her design focus.
4. Two immediately visible clickable project cards, different in visual identity yet unified by layout.
5. A concise four-step approach and real design focus areas.

## Publishing

GitHub profile READMEs appear only when there is a **public repository named exactly `sabnumpariyar-png` under the `sabnumpariyar-png` account** and its root contains `README.md`.

The files in this bundle are designed to be placed at the root of that new repository, preserving the `assets/` folder.

The short bio must separately be pasted into GitHub's profile **Bio** field. The profile README does not change account settings or the avatar. Set `Location: Finland` if desired; don't set a precise city without Sabnam's approval. Feature/pin KIERTO and TRACE as the two most relevant portfolio repositories.
